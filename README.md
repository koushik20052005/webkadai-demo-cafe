# Kapi Kottai — WebKadai Demo Café Website

A premium demo website for a fictional specialty coffee house ("Kapi Kottai", Alwarpet, Chennai), built by **WebKadai** to show café clients what their business website could look like.

## What's inside
- Single self-contained `index.html` (no build step, no server)
- 3D mouse-tilt hero, scroll animations, animated counters, rotating badge
- Working menu with 4 categories (24 items) and an **order tray** — customers add items and send the full order to WhatsApp in one tap
- Real opening-hours status ("Open now · closes 10:30 PM"), story, gallery, reviews

## Deploy on Vercel
Import this repo at [vercel.com/new](https://vercel.com/new) → Deploy. No settings to change — it's a static site (`index.html` at root, images in `assets/`).
